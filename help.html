Help and Usage Instructions

What is Vani Rachanakar?

Vani Rachanakar is a simple tool for creating listening activities from conversations. A teacher can prepare a conversation, choose a voice and speaking pace for each dialogue entry, and create an audio-supported conversation for students.

Getting Started

1. Choose how to enter the conversation

On the welcome screen, choose one of the two options:

  • Read from File – load a text file. Each paragraph, separated by a blank line, becomes one dialogue entry.
  • Input Manually – type or paste the dialogue entries directly into the editor.
2. Check each dialogue entry

For every entry, select the voice you want to use and choose the speaking pace. You can change these settings independently for each entry.

3. Test the voice

Click Test to hear the selected entry. If necessary, change the voice or pace and test it again.

4. Add more entries

Use the + button to add another dialogue entry when entering the conversation manually.

5. Create the conversation

Enter the desired filename and click Create Web Page. Vani Rachanakar will generate the complete conversation page.

Using the Created Conversation

The generated conversation opens in a new browser tab. The original Vani Rachanakar window remains open, so you can return to it, make changes, and create the conversation again if required.

The generated HTML page is self-contained and can be saved and used offline. The accompanying audio is included in the page.

Important: After the conversation opens in the new tab, use the browser's Save option to choose where you want to store the HTML file.

Preparing a Text File

When using Read from File, prepare the text file with one dialogue entry in each paragraph.

Separate dialogue entries with a blank line.

Example:

Hello, Ravi. How are you?

I am fine, thank you. How about you?

I am fine too.

A Simple Workflow

  1. Prepare or import the conversation.
  2. Select a voice for each entry.
  3. Select the speaking pace.
  4. Test the entries.
  5. Give the conversation a filename.
  6. Create the web page.
  7. Save the generated HTML file.
  8. Use it in class, including offline.
